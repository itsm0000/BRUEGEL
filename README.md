# AI Drawing Tutor ("GhostFlow")

An intelligent, real-time drawing assistant that teaches touch and technique.

## Features
-   **Immersive Drawing**: UI automatically fades out when you draw.
-   **Ghost Guide**: Follow the dashed lines to learn shapes and strokes.
-   **Real-time Feedback**:
    -   <span style="color: green">Green</span>: High accuracy
    -   <span style="color: red">Red</span>: Deviation > 15px
-   **Lessons**: Circles and Straight Lines.
-   **Performance**: Native HTML5 Canvas + Pointer Events for 60fps+ tracking.

## Tech Stack
-   React + TypeScript
-   Vite
-   Tailwind CSS
-   Lucide Icons

## Getting Started

1.  **Install dependencies**:
    ```bash
    npm install
    ```

2.  **Start application**:
    ```bash
    npm run dev
    # or double-click launch.bat
    ```

3.  **Build**:
    ```bash
    npm run build
    ```
